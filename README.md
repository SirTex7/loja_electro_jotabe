# Electro Jotabê — Site de Catálogo

Site estático de apresentação de produtos para a Electro Jotabê, uma loja de eletrodomésticos, equipamentos de TV/som e produtos de cuidado pessoal.

## Sobre o projeto

Catálogo online sem funcionalidade de compra — foco na apresentação clara dos produtos, promoções e contactos da loja, com layout responsivo para telemóvel e desktop.

## Funcionalidades

- Mega-menu de produtos organizado por categorias e subcategorias (Eletrodomésticos, TV e Som, Cuidado Pessoal)
- Filtros e ordenação de produtos (preço ascendente/descendente, mais vendidos)
- Página de promoções com os produtos em desconto
- Badges de eficiência energética (classe A–G)
- Menu de navegação em slide para mobile
- Página de contactos com mapa incorporado

## Tecnologias
